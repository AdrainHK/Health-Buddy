## 优先级规则

清单原文：

- 1级（最高优先级，主决策依据）：国家卫健委诊疗规范+中华医学会精神医学分会正式临床指南
- 2级（补充细化依据）：国内专家共识、心理治疗技术规范、分阶段干预方案
- 3级（对标参考依据）：国际学会指南（APA、NICE、WHO）
- 4级（兜底细则）：心理评估量表、危机干预流程、心理咨询伦理、身心共病管理规范
- 总则：国内官方指南＞国内专家共识＞欧美国际指南；全部剔除已被替代旧版；覆盖筛查评估、抑郁/焦虑/双相/强迫、精神分裂症、躯体心理障碍、睡眠障碍、危机自杀干预、青少年心理、职场压力、身心慢病共病、心理治疗技术、伦理规范，消除AI决策盲区。
- 版本质控说明：决策层级严格锁定：1级官方指南为核心决策主干，2级共识提供分阶段干预方案，3级国际指南仅作证据对标，不优先采信；

冲突处理（所有专家相同，已写进专家提示词）：两张已确认卡片的说法冲突时，采用优先级高（数字小）的来源；同级冲突时国内来源优先于国际来源，即国内指南＞国内共识＞国际指南。

## 使用范围

- advice：健康管理内容（生活方式、监测、随访），摘成卡片并经医学顾问确认后，可以作为要点和建议的依据。
- referral_only：诊断、治疗、用药、手术操作、急救、专科疾病类文件，只用来识别什么时候该建议转介，不能作为要点和建议的依据；引用这类卡片的要点和建议会被后端校验移除（规格 5.2 第 1 条）。
- 拿不准时一律标 referral_only。

## 条目卡片

暂无。条目卡片的编写方式等产品负责人决定后再开始（规格 5.3）。卡片由医学顾问从已确认的来源中摘写，或由 Claude 起草后经顾问审核（规格 5.1）。卡片里的“可引用数值”必须由顾问核对原文后填写，不能凭记忆补。没有卡片之前，专家的所有要点都只能描述数据（data_only）。

卡片格式：

```
### S1-01
- 来源：S1，第 X 章 第 X 节（页码或条款号）
- 要点：用自己的话概述的一条建议或说明
- 可引用数值：如“xx mmol/L”（没有就写“无”）
- 适用人群：如“成人，非妊娠”
- 确认：顾问姓名或代号，YYYY-MM-DD
```
