暂无。条目卡片由医学顾问从已确认的来源中摘写，或由 Claude 起草后经顾问审核（规格 5.1）。卡片里的“可引用数值”必须由顾问核对原文后填写，不能凭记忆补。没有卡片之前，专家的所有要点都只能描述数据（data_only）。

卡片格式：

```
### S1-01
- 来源：S1，第 X 章 第 X 节（页码或条款号）
- 要点：用自己的话概述的一条建议或说明
- 可引用数值：如“xx mmol/L”（没有就写“无”）
- 适用人群：如“成人，非妊娠”
- 确认：顾问姓名或代号，YYYY-MM-DD
```
