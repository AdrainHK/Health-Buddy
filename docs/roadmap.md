# 健管AI助手 · 开发路线图（里程碑版）

> 2026年10月15日 · 依据 [功能清单第三版](feature-list.md)
> 开发方式：Adrain 负责需求、取舍和验收；全部代码、测试、检查由 Claude Code 完成。
> 不按周排期，一次只做一个里程碑，做到满意再进入下一个。

---

## 一、每个里程碑怎么做

1. **规格**：Claude 在 `docs/specs/` 写需求规格，提一个 PR，Adrain 确认或修改。
2. **实现**：按规格分成若干个小 PR，每个都带测试；涉及 AI 的部分同时写评测用例。
3. **自检**：类型检查、单元测试、端到端测试、AI 评测全部通过；租户隔离和产品边界由审查子代理检查。
4. **试用**：部署到预览环境，Adrain 点开就能试。
5. **验收**：Adrain 提意见，Claude 修改，直到 Adrain 说“通过”，这个里程碑才结束。

**完成标准（每个里程碑都一样）**：功能符合规格；关键流程有自动化测试；AI 输出有评测用例且通过；没有已知缺陷；界面在电脑和手机上都能正常使用；Adrain 验收通过。

## 二、技术选型

| 层 | 方案 |
|---|---|
| 仓库 | pnpm + Turborepo 单仓库 |
| 健管师工作台 | React + TypeScript + Vite（以后可用 Tauri 打包成桌面端） |
| 平台和运营商后台 | 同上，独立应用 |
| 客户端 | 先做 H5 网页版，再做微信小程序（Taro） |
| 后端 | Node.js + NestJS + TypeScript |
| 数据库 | PostgreSQL（行级安全做租户隔离）+ pgvector（知识库检索） |
| 队列和定时任务 | Redis + BullMQ |
| 大模型 | Claude API，经自建大模型网关调用；复杂分析和专家用能力强的型号，伴侣日常陪聊和批量任务用速度快、成本低的型号 |
| 报告识别 | Claude 直接读取报告图片和 PDF，提取结构化指标 |
| 测试 | Vitest、Playwright、自建 AI 评测集 |
| 部署 | Docker；预览环境和正式环境在第0个里程碑时确定云服务商 |

全栈统一用 TypeScript，前后端共用类型定义，Claude Code 写出的代码最稳定。

## 三、里程碑

### 第一部分：核心版本（可以给试点协会使用）

| # | 里程碑 | 内容 | 做完能看到什么 |
|---|---|---|---|
| M0 | 地基 | 单仓库、持续集成、代码规范；账号和登录；多租户数据模型（平台、运营商、机构、健管师、客户）；大模型网关；合成测试数据；设计规范 | 能登录一个空的工作台，测试和检查自动运行 |
| M1 | 工作台框架 | WorkBuddy 式三栏布局；问一问、想一想、做一做三种模式；流式对话和执行步骤展示；`/` 技能和 `@` 引用；结果区和审核栏；技能框架 | 能和 AI 对话，能调用一个示例技能，产物须审核才能发出 |
| M2 | 客户档案 + AI评估助手 | 统一客户档案；报告识别和指标提取；专业版和通俗版解读；风险分层；面谈提纲 | 上传一份体检报告，得到解读草稿，审核后发给客户 |
| M3 | 专家智能体中心 | 专家引擎（路由、并行调用、汇总、分歧标注、调用过程展示）；首批6个专家（内分泌与代谢、心血管、营养、运动康复、心理、检验解读）；直接提问和分析时自动调用 | 在专家中心提问；解读报告时看到“已调用内分泌专家、营养专家” |
| M4 | 客户数字孪生 | 画像和时间轴；红黄绿状态；3到6个月趋势预测；异常进入跟进清单；一键请专家解读 | 打开客户卡片就能看到孪生 |
| M5 | 方案生成器 + 智能随访 | 饮食、运动、作息、心理方案；食谱和运动库；随访日程、话术、记录整理 | 一键生成方案和随访计划 |
| M6 | AI健康伴侣 | 客户端（H5）；陪聊和长期记忆；档案答疑；打卡提醒；信息收集；紧急预警；所有边界规则 | 用测试客户账号和伴侣聊天，健管师端收到信息和预警 |
| M7 | SaaS运营后台 | 平台总后台（开通运营商、套餐）；运营商后台（品牌定制、批量开通健管师、运营看板） | 开通一个协会，协会用自己的品牌给健管师开账号 |
| M8 | 科普内容工厂 + 首页 | 文章、讲座PPT、社群稿；合规用词检查；工作台首页（跟进清单、待审核、预警、随访） | 核心版本完整可用 |

**到这里是“试点版”**：可以交给一个协会和几位种子健管师真实使用，收集反馈再继续。

## 四、需要你在过程中准备的东西

| 什么时候 | 需要什么 |
|---|---|
| M0 开始前 | Claude API 密钥（放进部署平台的密钥设置，不发在聊天里） |
| M0 结束前 | 选一个云服务商，用于预览环境和以后的正式环境 |
| M3 开始前 | 首批6个专家的知识来源：希望引用哪些指南和共识。最好有一位懂医学的顾问帮忙看专家的回答 |
| M7 开始前 | 第一个试点协会的名称、Logo 和品牌色 |
| 试点版完成后 | 联系试点协会和种子健管师 |
